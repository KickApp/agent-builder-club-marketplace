# Vendor Price Variance Monitor

Built by [Oscar Setiawan](https://www.linkedin.com/in/profitwithoscar), founder of KPI
Advisors and Real Estate BFF, for
[Agent Builder Club](https://www.agentbuilder.club/builders/oscar-setiawan/vendor-price-variance-monitor).

## Install

```text
/plugin marketplace add KickApp/agent-builder-club-marketplace
/plugin install oscar-setiawan@agent-builder-club
```

## What it does

Compares each vendor's contracted or expected monthly price, which you supply, to what
actually posted on the card or bank feed. It flags any vendor charging more than the
contract and any silent price creep across recent months.

Say things like "did our SaaS vendors go up in price" or "check this month's vendor charges
against contract".

## Safety

Read-only. It never edits, disputes, or pays a transaction.
