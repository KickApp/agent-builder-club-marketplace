# New Firm Revenue Planner

Built with [Logan Graf](https://www.linkedin.com/in/logangraf), founder of Counter, for
[Agent Builder Club](https://www.agentbuilder.club/builders/logan-graf/new-firm-revenue-planner).

## Install

```text
/plugin marketplace add KickApp/agent-builder-club-marketplace
/plugin install logan-graf@agent-builder-club
```

## What it does

Starts from what a new firm owner wants to take home and ends with how many clients they
need, the lowest monthly price that still hits the goal, and whether a proposal clears that
price. The plan is a PDF with a tier chart, sensitivity tables for client mix, margin, and
hiring, and every input tagged with where it came from.

Say things like "how many clients do I need to make $100K" or "does a $550 a month proposal
still hit my goal".

## Safety

Read-only. It never changes the books. The plan covers firm economics only, not tax advice.
