# Client Meeting

Built by [Josh Schneider](https://MultiplyAdvisors.com), CEO of Multiply Advisors, for
[Agent Builder Club](https://www.agentbuilder.club/builders/josh-schneider/client-meeting).

## Install

```text
/plugin marketplace add KickApp/agent-builder-club-marketplace
/plugin install josh-schneider@agent-builder-club
```

## What it does

Prepares a one-page client meeting brief from the books: financial highlights since the last
meeting, open bookkeeping items, anomalies, and suggested talking points. When calendar or
email connectors are available it adds context from them; without them it works from the
books alone.

Say things like "prep for my meeting with this client" or "what should I cover on the call".

## Safety

Read-only. It never changes the books. The brief is for a qualified professional to review
before the meeting.
